# Codex instructions for this repo

## Project purpose
Build a local-first, AWS-compatible pipeline to monitor Calgary real-estate listings:
- daily scrape
- idempotent ingestion
- property identity deduplication
- history tracking
- low-cost AWS migration

## Constraints
- ARM64 containers only
- Docker + LocalStack + Postgres
- Idempotency > performance
- Preserve raw + normalized + error data
- Do not introduce managed/cloud-only services in dev

## Repo structure
- infra/: local AWS emulation + DB
- services/: scraper, parser, api
- scripts/: bootstrap helpers
